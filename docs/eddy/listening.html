Patches

1. Disintegrating loop

Fathom or Rigging → Eddy → Fog

Play a slow phrase and record 20–40 seconds. Set WEAR around 2 o'clock and SMEAR at noon, and leave it for ten minutes. Patch a slow clock into TRIG to restore it every few minutes so the decay starts over.

2. Sound on sound drone

Fathom → Eddy → Narrows → Fog

Record 10 seconds of silence to set the length. Hold DUB on with DUB LEVEL at noon and play single notes, one per pass. Add a little WEAR so the old layers darken as they fade.

3. Half-speed field recording

WAV → Eddy → Fog · Sway → START CV

Load a field recording, set SPEED to +0.5, LENGTH to a few seconds and SMEAR to full. A very slow Sway into START CV drifts the window across the file. Fog nearly fully wet.

4. Reverse swells

Squall → Rigging → Eddy → Wake · Squall → PLAY

Record a struck sound. Set SPEED to −1, LOOP off, and trigger PLAY from Squall. Each hit plays backwards into silence.

5. Tape as an oscillator

Sequencer or Shoal → V/OCT · Eddy → Narrows · Sway → START CV

Load any file and set LENGTH to minimum. START now selects the timbre, so modulate it slowly.

6. Stutter and scan

Squall CV → START CV · Squall gates → PLAY · EOC → anything

A short LENGTH (100–300 ms) with random Start positions. EOC can clock something else, so the patch follows the loop's own length.

7. Self-clocked dub

EOC → Squall or Shoal → Rigging → IN L

DUB on at a low DUB LEVEL. Each turn of the tape adds one new strike to itself.

8. Wow and flutter

Sway → SPEED CV

The attenuverter barely open, on a loop at speed +1, with a little WEAR. The simple "old tape" sound, and a good test of how heavy a speed change feels.
