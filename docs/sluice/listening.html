SLUICE

Listening list · build 2.0.39 · 2026-11-24

Sluice is a quad VCA, 10 HP: four rows, each with an input, a Level dial, a CV jack, a light and an output, all DC-coupled and polyphonic. Unpatched inputs take the signal from the row above (the rope) and unpatched outputs mix into the row below, so it works as four VCAs, one signal split four ways, or a four-channel mixer; one Lin/Exp switch sets the response for all rows. Ticks and notes are kept in this browser; Copy notes puts them on the clipboard to paste back. Items marked untested are paths no automated run could reach: the lights, the panel, the tooltips and the switch. The Exp curve, the 10 ms Level smoothing and the closed default are first guesses, to be set by ear here.

Verdicts (first guesses; say what to change)

WhatThe question
LEVEL DEFAULTEvery Level opens at 0 %, fully closed, so a new Sluice is silent until a dial is turned. Keep, or should row A open to some level?
EXP CURVEExp is linear in dB over 60 dB, so 50 % is about −30 dB, with a short ramp to true silence over the bottom 5 % of the dial. Does a fade sound even? Is 60 dB the right depth, and is the bottom of the dial easy to set for a very quiet layer?
CV SCALECV adds to Level, 10 V across the whole dial (1 V per division). With Level at noon a ±5 V LFO opens and closes the row. Is that the right amount, or would a CV attenuator be missed?
SMOOTHINGLevel is smoothed over about 10 ms; CV is not; the Lin/Exp switch changes the level at once. Is any of the three wrong in a drone: a click on the dial, a hard CV, a jump when the switch is flicked?
THE ROPE AND MIXOne signal into A with only D patched and every Level open comes out 4× (+12 dB); nothing scales the mix. Keep the manual's warning as it is, or should the sum be scaled down?
THE LIGHTEach light shows Level plus CV before the curve, so it reads the same in Lin and Exp (the design spec said it glows with the gain). Does it say what you need at a glance on a slow fade?
STEREONo stereo features: Merge, one row, Split is the recommended patch. Is that enough, or would a linked pair of rows be missed? (Issue 64, polyphony, lists Sluice as already polyphonic.)

Patches

1. Breathing drone

Fathom Left → Sluice A · Sway Sine → Sluice A CV · Sluice A → Fog IN L

Set A Level to noon and the Sway to a slow rate. The ±5 V sine opens and closes the row from silent to fully open. Move Level up and down and listen to where the swing flattens at the top or bottom.

2. Envelope as a VCA

Squall Gate → Beacon GATE · Beacon OUT → Sluice A CV · Fathom Left → Sluice A

Leave A Level at 0 so the 0–10 V envelope works as a classic VCA. Switch between Exp and Lin and hear how the same envelope feels.

3. One signal, four layers

Hadal Left → Sluice A · Neap C1 → A CV · C3 → B CV · C5 → C CV · C7 → D CV · only D out patched → Fog IN L

The rope carries Hadal to all four rows; each row is opened by its own slow cycle. At Exp, 25 % is already −45 dB per row, so start higher: about 80 % per row (−12 dB each) gives unity for four equal copies. The four copies add up (+12 dB at full).

4. Stereo through one row

Fathom Left and Right → VCV Merge → Sluice A · Sluice A out → VCV Split → Fog IN L and IN R · Neap TIDE → A CV

One Level and one CV, so the two sides cannot drift apart. Turn Level and listen for the image leaning to one side; it should not.

5. Four-channel mixer

Fathom Left → A · Rigging Left → B · Hadal Left → C · Eddy Left → D · only D out patched → Fog IN L · Squall Swell → B CV

Patch only D so it carries all four rows. Balance with the four Levels; the Squall swell moves the Rigging layer in and out.

6. Gating an LFO

Sway Sine → Sluice A · Beacon OUT → A CV (Level 0, switch on Lin) · Sluice A → Fathom Detune CV

The LFO reaches Fathom only while the envelope is open; on Lin a half-open row passes exactly half of it.

7. Eight voices through one row

Neap ALL → Sluice A · Beacon OUT → A CV · Sluice A out → a poly scope

The row has 8 voices out; the mono CV moves every voice together. Then try a polyphonic CV (a 4-channel cable) and see what voices 5 to 8 do: a short CV gives them 0 V of CV, so they sit at the Level setting. They close only with Level at 0.
