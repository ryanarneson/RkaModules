# Eddy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eddy, a 16 HP stereo tape loop in the Instrument look that is filled by recording or by loading a WAV (up to 5 minutes), with Speed through zero, a Start and Length window, Dub, Wear, Smear, a kept original with Restore, a play trigger, a waveform window, file save, and the tape kept with the patch.

**Architecture:**
- **Shared, Rack-free, under `src/`:** `WavFile` (read and write, on vendored `dr_wav`), `Resample` (offline rate conversion), `Tape` (a stereo buffer that stands still, a fractional read in either direction, a write head that travels with the read), `Overview` (the reduced copy the window draws). Fetch and Spindrift reuse them.
- **Engine:** a Rack-free `rka::EddyEngine` (`src/eddy/EddyEngine.hpp`) from small headers: the control laws, wear, and the transport. It owns no memory: tapes arrive as a `TapeSet` handed over by an atomic pointer and go back the same way, so nothing is allocated, freed, locked or copied in bulk on the audio thread.
- **Module:** `Eddy.cpp` maps ports and params onto the engine and runs one worker thread for everything slow: loading, converting, the two bulk copies (original to tape, tape to original), saving.
- **Window:** `TapeWindow` in `src/widgets.hpp`, drawing an `Overview`.
- **Panel:** the draft `"Eddy"` entry, kept as a patch at `docs/plans/2026-11-21-eddy-panel-draft.patch` (apply with `git apply`; delete it in Task 1), as the mockup the user approved.

**Tech Stack:** C++11 plugin code (Rack SDK 2.6.6), C++17 offline tests with `src/testing.hpp`, `dr_wav` (public domain, vendored), the Python 3 panel generator, Inkscape.

**Spec:** `docs/specs/2026-11-21-eddy-design.md`, mockup `docs/specs/2026-11-21-eddy-mockup.png`. Testing rules: `TESTING.md`. Code to read first: `src/DelayLine.hpp` (the Hermite read), `src/DelayTap.hpp` (how a join is faded), `src/wake/WakeEngine.hpp` and `Wake.cpp` (frame, control rate, ramps, the soft limit, latches), `src/shoal/Shoal.cpp` (a widget drawn in a `SCREEN_` rectangle), `../Fundamental/src/WTVCO.cpp` (patch storage, `dr_wav`). Read the spec before any task. Where this plan and the spec disagree, the spec wins; ledger the difference.

## Global Constraints

- **Build:** `RACK_DIR=$HOME/ws/sdk/Rack-SDK-2.6.6-mac-arm64`. Agents start Rack only through `make smoke`. Before every `make install`, `mac_dist` or `cross_build`: `tools/bump_version.sh "<what changed>"`, and clear older `rka-*` packages from Rack's plugins folder.
- **Branch:** work on a branch `eddy`, not `main`.
- **Repo:** unit tests only; no audio files (tests make their WAVs in a temp folder and delete them), no test results beyond unit tests (they go on `/Volumes/share1/VCVRACK/`).
- **Every test is shown to fail** (a mutation, named in the ledger; `sleep 1` before the rebuild). No libm per sample (`src/FastMath.hpp`); NaN-safe; no allocation, free, lock or file access in `process`.
- **Ids** (panel, layout header, module, in this order): params `SPEED`, `SPEED_ATT`, `START`, `LENGTH`, `WEAR`, `SMEAR`, `DUB_LEVEL`, `MIX`, `REC`, `DUB`, `PLAY`, `LOOP`, `RESTORE`; inputs `START_CV`, `VOCT`, `SPEED_CV`, `L`, `R`, `REC`, `DUB`, `PLAY`, `RESTORE`; outputs `EOC`, `L`, `R`; lights `REC`, `DUB`, `PLAY`, `LOOP`; screen `TAPE`. Slug `Eddy`.
- **Tape:** stereo float at the engine's rate. Capacity C = min(300 s × fs, 2^24 frames) plus a tail of 10 ms; the manual states the length at 96 kHz and above. Empty at first.
- **Fades:** F = 10 ms for Rec, Dub, Play, Stop, retrigger, Restore, a window move, a new tape. All linear on the tape, equal-power where two reads of different audio overlap at the output.
- **Speed:** knob −2..+2, default +1, with flat stretches: within ±0.04 of −1, 0 or +1 it reads exactly that, and the law is continuous outside them. Plus Speed CV × attenuverter (−1..1, default 0) × 0.4 per volt. That sum glides with a 60 ms time constant, then is multiplied by 2^(V/OCT volts), which is smoothed over 2 ms only, and held to ±4.
- **Stopped:** output gain rises linearly from 0 at |speed| = 0 to 1 at |speed| = 1/64. Writing (Dub and Wear) fades linearly from 0 at |speed| = 1/16 to full at 1/8.
- **Window:** Start = clamp(knob + Start CV volts / 5, 0, 1) × tape length; knob 0..1, default 0. Length: knob k 0..1, default 1, L = 10 ms × (tape length / 10 ms)^k, held to the tape. A window past the tape's end wraps to its beginning. A window change leaves the head alone unless the head is now outside it; then it fades (F) to Start, or to the window's end when going backwards.
- **Join and Smear:** m = min(F, L / 4). Smear knob s 0..1, default 0: overlap o = max(m, s × L / 2). The join reads on past the window's end for as much of m as the tape holds there (the recorded tail, or tape beyond a window that stops short of the end); call that t. A turn is L − (o − t) long. At Smear 0 on a recording the turn is exactly L.
- **Voices:** up to 4 read voices; a jump (join, retrigger, Restore, window move, new tape) starts a new one and fades the last; when all are in use the oldest is cut by a 1 ms fade. The write head follows the newest voice.
- **Rec:** the REC button toggles; the REC jack records while above 1 V (0.1 V / 1 V Schmitt). Always at speed 1, forwards. The input is taken unchanged. Under 50 ms: thrown away, the tape before it stays. At C: ends by itself. After the end, a further m of input is taken as the tail. Then Play comes on from the start. IN R takes IN L when unpatched; polyphonic cables are summed.
- **Play:** the PLAY button toggles. A trigger at the PLAY jack turns Play on and starts from Start (the window's end when backwards). Loop off: at the window's end the tape stops and Play goes off. EOC: 10 V for 1 ms at each turn's end and at a one-shot's end.
- **Dub:** the DUB button toggles; the DUB jack dubs while above 1 V. Dub Level d 0..1, default 0.5: new layer gain = min(1, 2d), old tape kept = 1 − d². At d = 0 nothing is written. What is written passes a DC blocker (5 Hz) and a soft bound (identity below 8 V, ceiling 10 V). Inert on an empty tape, while recording, and while the tape plays from the original (see Restore).
- **Wear:** knob w 0..1, default 0. At 0 the tape is not written. Constants in `src/eddy/EddyTuning.hpp`, starting at: level per pass −0.5 w² dB; highs: each pass moves the tape 0.3 w² of the way to a 4 kHz one-pole low-pass of itself; saturation drive 1 + w into the soft bound; hiss per pass −70 dB re 5 V × w; dropouts 0.5 w² per second of tape passed, each 5 to 40 ms to a gain of 0.3 to 0.8 with 2 ms edges. Seeded. No setting may raise the tape's level.
- **Original and Restore:** a recording ending or a file loading sets the original. Restore (button or trigger): the voices fade (F) to reading the original at the same place, the worker copies original to tape, and reading returns to the tape when the copy is done (the two are then equal, so it is a switch). Recording's end uses the same path: it records into the original and plays from it until the tape is copied. Restore ends a dub; it is ignored on an empty tape and while recording. "Make this the original" is the worker copying tape to original.
- **Mix:** equal-power, 0 input alone, 1 tape alone, default 1. While recording or dubbing the input is added at unity whatever Mix says. Outputs: soft limit, identity below 8 V, ceiling 10 V.
- **Files:** WAV in: mono, stereo or more (first two channels), 8, 16, 24, 32-bit integer and 32, 64-bit float; ±1.0 is ±5 V. Longer than the tape: the first C frames. Out: 32-bit float stereo at the engine's rate, the whole tape, ÷ 5. Writes go to a temporary name beside the target and are renamed over it.
- **With the patch:** params (Rec is forced off on load); JSON `file` (path) and `keepTape` (default true); `tape.wav` and `original.wav` in the patch storage folder, each written only when its change counter has moved. `keepTape` false: nothing is stored, and a load reads `file` again if it exists.
- **Bypass:** IN L to L, IN R to R, with the normalling. **Initialize:** empties the tape, Play off, Loop on. A rate change: silence while the worker converts the tape and the original, then as before.
- **Panel:** rows and columns as the spec's Panel section; the window is the `TAPE` screen rectangle.

## Review Focus

1. **Files that lie or are huge:** a header claiming more frames than the file holds, 0 channels, a 0 Hz or 4 MHz rate, ADPCM or another compressed WAV, a 2 GB file, a folder, a path with non-ASCII characters (also on Windows): the tape stays as it was, nothing is allocated beyond the tape, the reason is logged. (Task 2, Task 9.)
2. **Trigger storms:** PLAY, RESTORE, REC and DUB driven at audio rate, together, also while a copy or a load is pending: bounded cost, no click over the stated bound, copies coalesce (one request waiting at most), the state afterwards is what the last edges ask for. (Task 7, Task 8.)
3. **Window extremes:** Length at 10 ms on a full tape with Smear at 1, Start CV as ±10 V noise, Speed at ±4 with V/OCT stepping every sample, a tape only 50 ms long: every read is inside the tape and its tail, a turn is never shorter than m, no NaN. (Task 3, Task 4, Task 8.)
4. **A tape arriving or leaving at a bad time:** a file landing while recording, dubbing or restoring; two loads in quick succession; a rate change during a load; the module deleted while the worker is busy: no leak, no use after free, the last request wins, the worker is joined before the engine is destroyed. (Task 7, Task 8, Task 9.)
5. **Patch storage that is partial or wrong:** `tape.wav` without `original.wav` or the reverse, the two at different lengths or rates, a file cut short by a crash, an unwritable folder: what can be loaded is (a lone file serves as both), otherwise the tape is empty; never a crash, always a log line. (Task 9.)

### Task 3: The tape and its heads (shared)

**Files:** Create `src/Tape.hpp`, `src/eddy/test_tape.cpp`. Modify `tests.mk` (`PLUGIN_MATH_TESTS`).

**Interfaces — Produces:**

```cpp
namespace rka {
struct Tape {
	static constexpr int GUARD = 4;          // frames either side for the interpolator
	// calloc, so untouched pages cost nothing. Never on the audio thread.
	bool allocate(size_t capacityFrames, size_t tailFrames);
	void release();
	size_t capacity() const;                 // frames, without the tail
	size_t tailCapacity() const;
	size_t length = 0;                       // frames in use
	size_t tail = 0;                         // frames of audio after `length`
	float* ch[2] = {nullptr, nullptr};
	// Hermite read of side c at frame p, 0 <= p < length + tail. Clamped; never outside.
	float read(int c, double p) const;
	// As read, but p wraps round [0, length): for a window that passes the end.
	float readWrapped(int c, double p) const;
};
// The write head. It remembers the last input, so the input can be placed
// between samples.
struct TapeWriter {
	void reset();
	// The head went from p0 to p1 this sample (|p1 - p0| <= 4; the caller splits
	// a move that wraps). For each whole frame passed, in the order passed:
	//   tape.ch[c][frame] = mix(c, tape.ch[c][frame], input as it was at that moment)
	// Slower than 1, the input between two frames is averaged, not dropped.
	template <class Mix> void write(Tape& tape, double p0, double p1, const float in[2], Mix&& mix);
};
}
```

### Task 7: The engine

**Files:** Create `src/eddy/EddyEngine.hpp`, `src/eddy/test_engine.cpp`, `src/eddy/test_transport.cpp`. Modify `tests.mk`.

**Interfaces — Consumes:** Tasks 3 to 6. **Produces:**

```cpp
namespace rka {
struct TapeSet {                       // made and freed off the audio thread
	Tape tape, original;
	Overview overview;
	bool allocate(float fs);           // capacity and tail from Global Constraints
	void release();
};
struct EddyFrame {
	enum { SPEED, SPEED_ATT, START, LENGTH, WEAR, SMEAR, DUB_LEVEL, MIX, PARAMS_LEN };
	float params[PARAMS_LEN] = {1.f, 0.f, 0.f, 1.f, 0.f, 0.f, 0.5f, 1.f};
	float speedCv = 0, voct = 0, startCv = 0;
	float recGate = 0, dubGate = 0, playTrig = 0, restoreTrig = 0;   // volts
	float inL = 0, inR = 0;
	bool inRPatched = false;
	bool recPress = false, dubPress = false, playPress = false, restorePress = false;   // true for one sample
	bool loop = true;
};
struct EddyResult {
	float l = 0, r = 0;
	bool eoc = false;
	bool recording = false, dubbing = false, playing = false;   // for the lights and the saved params
	bool empty = true;
	float head = 0, winStart = 0, winLength = 1, overlap = 0;   // fractions of the tape, for the window
	float seconds = 0;                                          // the tape's length
};
class EddyEngine {
public:
	explicit EddyEngine(uint32_t seed);
	// Audio thread.
	void process(const EddyFrame& f, EddyResult& out);
	// Any other thread.
	void setSampleRate(float fs);           // retires the set (silence until a new one is offered)
	void setTransport(bool play, bool dub); // after a patch load
	void clear();                           // Initialize, and the menu's Clear
	// A set to use: an empty one to record into, or a loaded tape (tape and original
	// equal, overview built). False if one is still waiting to be taken.
	bool offer(TapeSet* set);
	TapeSet* collect();                     // a set the engine is done with, or nullptr
	enum Copy { NONE, ORIGINAL_TO_TAPE, TAPE_TO_ORIGINAL };
	Copy copyWanted() const;                // the worker does it on live(), then calls copyDone()
	void requestCopy(Copy c);               // "Make this the original"
	TapeSet* live() const;
	void copyDone();
	uint32_t tapeChanges() const;           // moves whenever the tape is written
	uint32_t originalChanges() const;
};
}
```

Per sample: transport edges; controls every 16 samples (laws, window, wear amount); each voice reads the tape (or the original, while a copy is wanted) and advances by the speed; joins and jumps start voices; the write head runs `TapeWriter::write` with a `mix` of wear, then keep × old + add × input, then `WriteGuard`, and touches the overview; Mix and the limit. Recording writes the first 50 ms into a small array inside the engine, then into `original` from frame 0, so a short press costs nothing; at the end it asks for `ORIGINAL_TO_TAPE` and plays from the original meanwhile. With no set, or a set whose rate is not the engine's, the engine is silent and Rec is ignored. In tests a helper stands in for the worker (does the copy when wanted, between `process` calls).
