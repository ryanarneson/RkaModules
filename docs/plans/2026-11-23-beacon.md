## Global Constraints

- **Build:** `RACK_DIR=$HOME/ws/sdk/Rack-SDK-2.6.6-mac-arm64`. Agents start Rack only through `make smoke`. Before every `make install`, `mac_dist` or `cross_build`: `tools/bump_version.sh "<what changed>"` (`make install` clears older `rka-*` packages itself, #45; Windows copies to the share need the same care).
- **Repo:** unit tests only; no audio or test results in the repo (they go on `/Volumes/share1/VCVRACK/`).
- **Every test is shown to fail** (a mutation, named in the ledger; `sleep 1` before the rebuild: make on macOS has 1 s timestamps). No libm per sample (`src/FastMath.hpp`); NaN-safe; no allocation in `process`.
- **Ids** (panel, layout header, module, in this order): params `SHAPE`, `MODE`, `ATTACK`, `DECAY`, `SUSTAIN`, `RELEASE`, `PUSH`; inputs `ATTACK_CV`, `DECAY_CV`, `SUSTAIN_CV`, `RELEASE_CV`, `GATE`, `RETRIG`; outputs `ATTACK`, `DECAY`, `SUSTAIN`, `RELEASE`, `TRIG`, `OUT`, `INV`; lights `ATTACK`, `DECAY`, `SUSTAIN`, `RELEASE`. Slug `Beacon`, folder `beacon`, 10 HP. Tag `Envelope generator`, `Polyphonic`, `Slew limiter`.
- **Mode:** 0 GATE (switch up, the default), 1 TRIG, 2 HOLD.
- **Time law** (Attack, Decay, Release): knob k in 0..1, T = 0.001 s × 60000^k (noon ≈ 245 ms). CV: k + volts / 10, clamped to 0..1, so T stays in 1 ms .. 60 s. NaN reads as the knob alone.
- **Sustain:** level = 10 V × clamp(knob + volts / 10, 0, 1) in GATE and TRIG. In HOLD the input is the Sustain CV's volts plus 10 V × knob, clamped to ±10 V.
- **Defaults** (starting points; tuned at the listening stop): Attack 10 ms (k = 0.2093), Decay 300 ms (k = 0.5184), Sustain 0.5, Release 1 s (k = 0.6279), Shape 0.75, Mode GATE.
- **Stage rule:** a stage runs a phase p from 0 to 1, advancing by dt / T each sample with T the stage's time *now* (so a knob or CV change alters the rate, never the level). Level = start + (goal − start) × curve(p). Start is the level when the stage began. Every stage takes exactly its time wherever it starts; a stage whose start equals its goal ends at once.
- **Curve** (`Shape` s in 0..1, a = |2s − 1|, noon linear, computed, no table, no libm): rising stages (goal above start) use r(p) = (1 − a) p + a c(p); falling stages use f(p) = (1 − a) p + a d(p). Right of noon (classic): c(p) = 1 − (1 − p)^4, d(p) = 1 − (1 − p)^4 (fast start, long tail toward the goal). Left of noon (reverse): c(p) = p^4, d(p) = p^4 (slow start, falls late). Exactly 0 at p = 0 and 1 at p = 1 at every Shape.
- **Gates:** GATE and RETRIG: Schmitt 0.1 V / 1 V. PUSH held = GATE high on every channel.
- **Gate mode:** rising edge → Attack from the present level. Attack → Decay → Sustain while high. Falling edge at any stage → Release from the present level.
- **Trig mode:** rising edge → Attack from the present level; Attack always completes; then gate high → Decay → Sustain, gate low → Release from 10 V.
- **Rising edge while running** (both modes) and **RETRIG rising edge while the gate is high** → Attack from the present level. RETRIG does nothing while the gate is low.
- **Sustain stage:** the level follows the sustain level through a 2 ms one-pole (no step, an LFO on Sustain still moves it).
- **Hold:** the output slews toward the input: up at 10 V / T_attack per second, down at 10 V / T_decay. Gate A while limiting upward, D while limiting downward, S when the output is within 1 mV of the input (hysteresis: leaves S only beyond 2 mV); R low. GATE, RETRIG and PUSH ignored.
- **Mode switches:** one level per voice, shared. GATE/TRIG → HOLD: slew from the level. HOLD → GATE/TRIG: gate high → Attack from the level; low → Release from the level to 0 V (a rise when negative). GATE ↔ TRIG: the running stage carries on.
- **Outputs:** OUT 0..10 V (HOLD: ±10 V); INV = −OUT bit for bit; stage gates 10 V while the stage runs, at least one sample; TRIG a 1 ms 10 V pulse at every stage start including the return to idle, restarted (merged) by a start while high.
- **Polyphony:** channels = GATE's (1 if unpatched) in GATE/TRIG, the Sustain CV's (1 if unpatched) in HOLD; capped at 16. RETRIG and the CVs: a polyphonic cable per channel, mono to all. New channels start at 0 V, idle. Stage lights and the window follow channel 1.
- **Bypass:** Rack's default (outputs 0). **Saved:** params only. **Initialize:** every voice idle at 0 V. **Sample rate change:** stage, phase and level kept; times stay in seconds.
- **Window:** `screens=[("ENVELOPE", 4.4, 19.0, 42.0, 17.0)]`. Stage widths ∝ weights: A, D, R weight 1 + log10(T / 1 ms) (1 .. 5.78); Sustain weight 2.5. Running stage and its letter bright, the rest dim. The dot at channel 1's stage and phase on the drawn curve; in HOLD a scrolling line of channel 1's output, kept on the UI side (no audio-thread buffer).

## Review Focus

1. **A gate held high while the switch is moved through all three positions, at audio rate:** no jump in OUT, no stuck stage, gates and TRIG coherent (Task 4).
2. **Times at the 1 ms floor at 44.1 kHz and below (44 samples or fewer), and 60 s at 768 kHz (46 M samples):** exact length within one sample, phase never overshoots, float phase does not stall (keep p and dt in double) (Task 3).
3. **A GATE cable whose channel count changes while voices are running:** surviving channels keep their state; vanished ones stop; new ones start idle; no read past 16 (Task 4).
4. **Sustain CV as audio-rate noise in GATE mode, and as ±10 V steps in HOLD:** OUT stays inside 0..10 V (GATE) and ±10 V (HOLD), no NaN, gates do not chatter faster than the hysteresis allows (Tasks 3, 4).
5. **Typed tooltip values out of range or garbage ("0", "-5", "1e9", "abc", "90 s"):** clamp to 1 ms .. 60 s or are ignored; the shown text parses back to the same knob (Task 2).

```cpp
namespace rka { namespace beacon {
enum Stage { IDLE, ATTACK, DECAY, SUSTAIN, RELEASE };
enum Mode { GATE_MODE, TRIG_MODE, HOLD_MODE };
struct VoiceIn {                 // one channel, one sample
	float attack, decay, release; // seconds, already through stageSecondsCv
	float sustain;                // volts 0..10 (GATE/TRIG) or the Hold input, ±10
	float shape;                  // 0..1
	bool gate, retrig;            // after Schmitt (edges are the voice's job)
	Mode mode;
};
struct VoiceOut {
	float level;                  // OUT
	bool stageGate[4];            // A, D, S, R
	bool trig;                    // TRIG high this sample
};
struct Voice {
	void setSampleRate(float fs); // keeps stage, phase, level
	void reset();                 // IDLE, level 0, pulse off
	void process(const VoiceIn& in, VoiceOut& out);
	Stage stage() const;
	double phase() const;         // 0..1 within the stage; Hold: 0
	float level() const;
};
}}
```

State in double: phase, its step, level. Hold's three states map onto ATTACK (rising), DECAY (falling), SUSTAIN (settled) for the gates, with the 1 mV / 2 mV hysteresis. The trigger counter is in samples, `max(1, round(0.001 × fs))`.
