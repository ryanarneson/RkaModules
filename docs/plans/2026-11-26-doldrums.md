# Doldrums Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Doldrums, a 16 HP stereo freeze and stretch: a 30 s ring tape of the input with a window on it, grains of it resynthesised with random phases (PaulStretch's method, written afresh), Stretch from 1 to a true stop, Position, Blur, Tilt, Shift, a tuned comb (Harmonics) played from polyphonic V/OCT, a RUN gate and play once, and a frozen tape kept with the patch.

**Architecture:**
- **Core:** Rack-free headers in `src/doldrums/`: the control laws (`Laws.hpp`), the ring tape (`Ring.hpp`), the read point and its passes as pure logic (`Pass.hpp`), the per-bin tables and their piecewise rebuilding (`Tables.hpp`), one grain's analysis and resynthesis (`Grain.hpp`), and the engine that stages a grain's work across samples and ties it to a frame of params and inputs (`DoldrumsEngine.hpp`).
- **FFT:** pffft, vendored in `src/dep/pffft/` and wrapped by `src/Fft.hpp`, compiled into the plugin and into the tests.
- **Window:** `TapeView.hpp`, a reduced copy of the ring and a snapshot of the marks, handed to the UI thread as Spindrift's `GrainView.hpp` is.
- **File:** `TapeStore.hpp`, the frozen tape's file and its rate conversion on a worker, after Spindrift's `BufferFile.hpp` / `BufferSave.hpp` and Eddy's `TapeJobs.hpp`.
- **Module:** `Doldrums.cpp` maps params, ports, lights, menu and saved state onto the engine and draws the window.

**Tech Stack:** C++11 plugin code (Rack SDK 2.6.6), C99 for vendored pffft, C++17 offline tests with `src/testing.hpp`, the Python 3 panel generator, Inkscape.

**Spec:** `docs/specs/2026-11-26-doldrums-design.md`, mockup `docs/specs/2026-11-26-doldrums-mockup.png`. Testing rules: `TESTING.md`; aliasing: `docs/DSP-ALIASING.md`. Code to read first: `src/beacon/` (a recent module end to end: engine frame and result, `bench.inc`, tests), `src/spindrift/SpindriftEngine.hpp`, `GrainView.hpp`, `BufferFile.hpp`, `BufferSave.hpp` and their tests (a frozen buffer kept with the patch, a view for a drawn window, their thread tests), `src/eddy/TapeJobs.hpp` and `WorkerBook.hpp` (rate conversion and tape swap), `src/WavFile.hpp`, `src/Resample.hpp`, `src/FastMath.hpp`, `src/hadal/Random.hpp`, `src/eddy/Wear.hpp` (`detail::softBound`), `TapeWindow` in `src/widgets.hpp`. Where this plan and the spec disagree, the spec wins; ledger the difference.

**Two deliberate differences from the spec:**
1. **pffft is vendored, not taken from the SDK.** The spec says "nothing is vendored". The SDK ships only `pffft.h` and the code inside `libRack`; the offline tests and CI build with no Rack (`tests.mk`), so they could not link it. pffft's licence is FFTPACK's (BSD-like), compatible with GPL-3.0-or-later. The plugin and the tests then run the same transform code (TESTING.md rule 9).
2. **A tape not frozen, with Position fully left**, has no room to travel either. The spec's "held" rule for a pass shorter than a grain is written for the frozen case; not frozen, such a pass simply returns every grain (the output follows the input 30 s late at any Stretch) and RUN stays high. Ledger it for the listening stop.

## Global Constraints

- **Build:** `RACK_DIR=$HOME/ws/sdk/Rack-SDK-2.6.6-mac-arm64`. Agents start Rack only through `make smoke`. Before every `make install`, `mac_dist` or `cross_build`: `tools/bump_version.sh "<what changed>"`.
- **Repo:** unit tests only; no audio or test results in the repo (they go on `/Volumes/share1/VCVRACK/`). Never hand-edit `res/`, `res-src/` or `*Layout.hpp`.
- **Every test is shown to fail** (a mutation, named in the ledger; `sleep 1` before the rebuild: make on macOS has 1 s timestamps). No libm on the per-sample path (`src/FastMath.hpp`, tables); NaN-safe (NaN or inf samples and CVs read as 0 V); no allocation, lock or free in `process`.
- **Licence:** nothing is copied from `~/ws/plugins/paulxstretch/Source/PS_Source` (GPL-2.0-only). Do not open it.
- **Ids** (panel, layout header, module, in this order): params `STRETCH`, `STRETCH_ATT`, `POSITION`, `POSITION_ATT`, `HARMONICS`, `HARMONICS_ATT`, `BLUR`, `ROOT`, `TILT`, `SHIFT`, `PARTIALS`, `WIDTH`, `FREEZE`, `MIX`; inputs `STRETCH_CV`, `POSITION_CV`, `HARMONICS_CV`, `L`, `R`, `FREEZE`, `TRIG`, `VOCT`; outputs `RUN`, `L`, `R`. Slug `Doldrums`, folder `doldrums`, 16 HP. Tags `Effect`, `Granular`, each checked against Rack's tag list (it has none for spectral work).
- **Params:** STRETCH 0..1 (dial fraction), default 0.5 (x8); the three ATTs −1..1, default 0; POSITION 0..1, default 1 (now); HARMONICS 0..1, default 0; BLUR 0..1, default 0; ROOT −36..36 semitones from C4, snapped, default −24 (C2); TILT −1..1, default 0; SHIFT −24..24 semitones, default 0, exactly 0 within ±0.25; PARTIALS 1..32, snapped, default 8; WIDTH 0..1, default 0.393 (25 cents); FREEZE 0/1 latching, default 0; MIX 0..1, default 1.
- **CVs:** value = clamp(knob + att × volts / 10, 0, 1) for Stretch, Position and Harmonics. V/OCT: up to 16 channels, each a root; unpatched, one root.
- **Tape:** 30 s × engine rate frames, stereo, a ring. Freeze = button OR gate (Schmitt 0.1 V / 1 V). The input written to the tape is faded out and in over 5 ms at Freeze's edges. IN R unpatched takes IN L.
- **Grain sizes:** Short, Medium, Long = the power of two nearest (in log terms) 0.17, 0.34, 0.68 s × rate, capped at 131072: 8192 / 16384 / 32768 at 44.1 and 48 kHz, 16384 / 32768 / 65536 at 88.2 and 96 kHz. Hop = half a grain.
- **Stretch law:** t = dial fraction after CV. t ≤ 5/6: stretch = 2^(6t) (1, 2, 4, 8, 16, 32 at t = 0, 1/6, .. 5/6). 5/6 < t < 1: with u = 6t − 5, stretch = 32 / (1 − u)² (64 at u = 0.293, 128 at u = 0.5); a starting law, the builder may change it within the spec's words. t ≥ 1: held, pace exactly 0. pace = 1 / stretch. Tooltip: `x8.0` under 100, `x128` from 100, `held` at the stop.
- **Read point:** the absolute index one past the slice's last frame. Valid range [now − capacity + grain, now]. Lag L = round((1 − position) × (capacity − grain)); anchor = now − L. It advances pace × hop frames a grain. The rules for returns, Freeze, TRIG, Position, held and stop are the spec's "The read point, Position and Stretch", "Held" and "Play once, and RUN", and difference 2 above.
- **Spectral order** per grain and side: window, transform, loudness per bin, Shift, Blur, Tilt, comb, random phase, inverse, window, overlap-add. Bins under 16 Hz are zero.
- **Stereo:** default, one random phase φ per bin for both sides, the right side turned further by the phase of X_R × conj(X_L) (a unit vector from one reciprocal square root, no libm); Wide, a separate φ for each side.
- **Tilt:** gain = slope dB per octave × log2(f / 1 kHz), slope = 6 × TILT, held within ±24 dB. **Blur:** width = BLUR octaves, on power, energy kept. **Shift:** ratio 2^(semitones / 12), a bin's loudness shared between the two bins it lands between; past the top of the band dropped.
- **Comb:** root Hz = 261.6256 × 2^(ROOT / 12 + V/OCT volts); teeth at root × n, n = 1..PARTIALS, below Nyquist; tooth = exp(−½ (d / σ)²), d the distance in cents to the nearest tooth of any root, σ = 5 × 60^WIDTH cents but never less than one bin's width at that tooth; mask = the greatest over roots. Makeup g = min(8, 1 / sqrt(mean of mask² over the band)) (8 = +18 dB, a starting bound). Per bin: loudness × ((1 − h) + h × g × mask), h = Harmonics after CV; h = 0 skips the step.
- **Mix:** dry × cos(m π/2) + wet × sin(m π/2), m smoothed. Output through `softBound` (lift `eddy::detail::softBound` to a shared header if it is to be used from two modules).
- **RUN:** 0 / 10 V; the 1 ms dip is `max(1, round(0.001 × rate))` samples.
- **Staging:** steps `gap = max(64, round(64 × rate / 48000))` samples apart; the same count every grain; the grain sounds a fixed delay after its boundary. Worst single sample under 100 µs on the development Mac at 96 kHz, Long grain.
- **Menu and saved state** (`dataToJson`): `"grain"` 0/1/2 (default 1), `"wide"` (false), `"atEnd"` 0 go round / 1 stop (0), `"keepTape"` (true). The frozen tape: `tape.wav` in the patch's storage folder, 32-bit float stereo in volts at Rack's rate, written at save only when the Freeze button is on and it has not been written since it froze; removed when not frozen or `keepTape` is off. The seed is not saved.
- **Bypass:** inputs to outputs. **Initialize:** silent tape, defaults.

## Review Focus

1. **Position or Stretch CV at audio rate, stepped, huge, NaN or inf, with the attenuverter at either end:** the read point stays on the tape, every slice is read inside the ring, the output stays finite and bounded (Tasks 5, 9).
2. **Freeze tapped or gated faster than a grain, and TRIG at audio rate:** no step is written to the tape, the pass restarts each time without the read point leaving the tape, RUN is never left stuck high or low (Tasks 5, 8).
3. **The sample rate or the Grain setting changed in mid grain, while frozen, held or stopped:** no buffer is read at the wrong size, nothing clicks, a held sound stays or dissolves as the spec says (Tasks 8, 11).
4. **A hot or narrow input into a narrow comb at full Harmonics** (a ±10 V sine exactly on a tooth, DC, 16 roots at extreme V/OCT, roots above Nyquist or under 16 Hz): the makeup cannot blow the output up, the mask is finite, an empty comb gives silence and not NaN (Tasks 6, 9).
5. **The stored tape missing, truncated, of the wrong length, mono, or saved at another rate:** the patch opens with a silent or converted tape and no error dialog or crash; a save while the tape is being swapped writes a whole tape or none (Task 11).
