# Hadal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hadal, a 10 HP rumble-and-noise bed in the Instrument look. Three layers (Rumble, Hiss, Crackle) each have a level and a mono output, plus a stereo mix. Depth darkens every layer, and Drift makes the bed wander slowly. All five controls take CV through an attenuverter.

**Architecture:**
- **Engine:** a Rack-free `rka::HadalEngine` (`src/hadal/HadalEngine.hpp`), built from small headers: a seeded random source, the two noise layers, the crackle generator and the drift wander.
- **Module:** `Hadal.cpp` only maps ports, params and patch state onto the engine, as `Fog.cpp` does.
- **Panel:** a `"Hadal"` entry in `tools/gen_panels.py`, using existing primitives only (Fathom's numbered main dial, Fog's CV columns, `words` for the uneven km numerals).

**Tech Stack:** C++11 plugin code (Rack SDK 2.6.6), C++17 offline tests with `src/testing.hpp`, the Python 3 panel generator, and Inkscape 1.4.4.

**Spec:** `docs/specs/2026-11-16-hadal-design.md`, with its mockup `docs/specs/2026-11-16-hadal-mockup.svg`. Testing rules: `TESTING.md`. Read the spec before any task. Where this plan and the spec disagree, the spec wins; report the difference.

## Global Constraints

- **Build:** with `RACK_DIR=$HOME/ws/sdk/Rack-SDK-2.6.6-mac-arm64`. Agents never start VCV Rack except through `make smoke`.
  - `make install` is allowed for the user's listening checks. Before every install, the controller runs `tools/bump_version.sh "<what changed>"` (one version = one commit).
- **Test results:** test results beyond unit tests, and any audio, never go in the repo. They go on `/Volumes/share1/VCVRACK/`.
- **Voltages:**
  - At full, Rumble and Hiss each give about 1.6 V RMS. Crackle's long-term RMS at full (Drift 0, density 10/s) starts at 0.5 V, tuned by ear. No crackle tick peaks above ±5 V.
  - The mix of all three at full stays within ±10 V, with the soft limit idle at defaults.
  - No DC offset, and less than a stated share of rumble's energy below 15 Hz.
- **Knobs:**
  - **Depth:** param range [0, 1], shown as 0–11 km, default 0.5.
  - **Levels:** audio taper (gain = knob²). Defaults: Rumble 0.5, Hiss 0.3, Crackle 0, Drift 0.25.
  - **Attenuverters:** default 0.
  - **The law:** control = clamp(knob + cv/10 × att, 0, 1). A polyphonic CV uses channel 1. The module is monophonic.
- **Depth:**
  - corners move on a log scale, starting from Rumble about 120 Hz → 20–40 Hz, Hiss about 12 kHz → 1.5 kHz, and Crackle from bright short ticks to dark long thuds;
  - each layer's RMS stays within ±1.5 dB across Depth (Crackle: long-term RMS at Drift 0);
  - rumble never below about 15 Hz, hiss never above 16 kHz.
- **Drift:**
  - 0 is completely static;
  - full is level about ±4 dB, colour about ±⅓ octave, crackle density about 3–25/s;
  - a smooth random wander over 10–40 s, never periodic.
- **Crackle:** sparse random ticks averaging 10/s, randomly clustered, with sizes skewed and bounded; each tick at a random pan. Its knob sets level, not density. Per-tick energy is constant across Depth.
- **Stereo mix:**
  - Rumble is near-centre (L/R correlation ≥ 0.8), Hiss independent per side, Crackle randomly panned.
  - Each layer enters the mix through one fixed mix gain below 1, the same for all three.
  - A patched layer output leaves the mix, fading out or in over about 10 ms.
  - With R unpatched, L carries the mono sum at about one side's loudness on noise.
  - With nothing patched, no work is done; a layer that is neither patched nor in a patched mix is not computed.
- **Smoothing:** no zipper on any CV-driven gain or filter (30–40 ms one-poles, or per-sample interpolation).
- **Randomness:** seeded per instance on construction, from a seed the module passes in. No `rand()` and no global state.
- **Engine rules:**
  - no libm per sample (`src/FastMath.hpp`), no allocation in `process()`, no writable globals, denormals flushed;
  - NaN-safe comparisons, since tests build with `-funsafe-math-optimizations`;
  - filters stable from 44.1 to 768 kHz, with an unusable rate ignored and the last good one kept (48 kHz before any);
  - plugin code is C++11.
- **Generated files:** never hand-edit `res/`, `res-src/` or `src/hadal/HadalLayout.hpp`; run `make panels`.
- **Ids:** slug `Hadal`, folder `hadal`. They are pinned from Task 1:
  - params `DEPTH, RUMBLE, HISS, CRACKLE, DRIFT` (0–4), then `DEPTH_ATT … DRIFT_ATT` (5–9);
  - inputs `DEPTH_CV … DRIFT_CV` (0–4);
  - outputs `RUMBLE, HISS, CRACKLE, L, R` (0–4).
- **Bypass** silences all outputs.
- **Before a task is done:** `make test`. From Task 7 on, also `make` and `make smoke`, and look at `build/screenshots/Hadal.png`.

## Review Focus

1. **Patching and unpatching a layer output while it plays.** L/R changes by exactly that layer's contribution, with no step above the stated bound (`patch_unpatch_no_click`, Task 5).
2. **Square-wave CV at 50 Hz on every input at full attenuverter.** It stays finite and bounded, with no zipper steps (`square_cv_no_zipper`, Task 5).
3. **R patched or unpatched mid-stream.** L switches between the mono sum and left with no click (`mono_normal_switch_no_click`, Task 5).
4. **Sample-rate changes while running** (44.1 kHz, then 768 kHz, then 48 kHz). There is no NaN, and Depth's spectral centroids are right again at the final rate (`rate_change_recovers`, Task 6).
5. **Two Hadals in one patch** must not sound identical, and one seed must rerun bit-identically (`seeds_differ_and_repeat`, Task 5).

### Task 2: Random source and the noise layers (Rumble, Hiss)

**Files:**
- Create: `src/hadal/Random.hpp`, `src/hadal/NoiseLayer.hpp` and `src/hadal/test_layers.cpp`.
- Modify: `Makefile` (`MODULES += hadal`) and `tests.mk` (add `build/test/hadal/test_layers` to `PLUGIN_MATH_TESTS`).

**Interfaces (namespace `rka::hadal`):**
- `struct Random`:
  - `void seed(uint32_t s)`;
  - `uint32_t next()`;
  - `float uniform()` in [−1, 1);
  - `float unit()` in [0, 1).
  - A xorshift or PCG generator with no global state.
- `struct Rumble`:
  - `void setRate(float fs)`;
  - `void seed(uint32_t s)`;
  - `void setDepth(float d01)`;
  - `void setColour(float octaves)` (Drift's offset);
  - `void process(float& l, float& r)` gives a unit-level stereo pair (RMS 1.0 before gain), highly correlated, with the corner set by Depth and a high-pass near 15 Hz.
- `struct Hiss`: the same methods. Independent noise per side, low-passed by Depth and high-passed around 200–300 Hz.

- [ ] **Step 1: Write the failing tests** in `test_layers.cpp` (48 kHz, 20 s renders unless stated):
  - `rumble_centroid_falls_with_depth`: the spectral centroid at Depth 0, 0.25, 0.5, 0.75 and 1 strictly decreases, and the Depth 1 centroid is below 60 Hz.
  - `hiss_centroid_falls_with_depth`: as above. The Depth 0 centroid is above 3 kHz and the Depth 1 centroid below 1 kHz.
  - `layer_level_flat_across_depth`: each layer's RMS at those five Depths is within ±1.5 dB of 1.0.
  - `rumble_little_below_15hz`: the share of rumble energy below 15 Hz is under the stated bound (set from measurement, about 5 %), at Depth 1.
  - `no_dc`: |mean| < 1e-3 over 10 s for each channel of each layer.
  - `rumble_correlated_hiss_not`: rumble's L/R correlation ≥ 0.8, and hiss's |correlation| < 0.1.
  - `no_pitch`: no FFT bin more than 12 dB above its ±1/3-octave smoothed neighbourhood, for either layer at three Depths.
  - `no_loop`: the normalised autocorrelation stays under 0.1 for lags from 50 ms to 10 s.
  - `same_seed_repeats_other_differs`.
  - `stable_at_all_rates`: at 44.1k, 96k, 192k and 768k, outputs are finite, the centroids are within 10 % of their 48 kHz values, and the levels within ±1.5 dB.
- [ ] **Step 2: Run them and see them fail.** Run `make test`. Expected: compile failure, because the headers are missing. The bench guard fails until Task 6 adds `bench.inc`; that is accepted, as on Fog (nothing is pushed in between).
- [ ] **Step 3: Implement** `Random.hpp` and `NoiseLayer.hpp`.
  - The noise colours and filter orders are the builder's choice; brown or pink are natural bases for rumble.
  - Normalise each layer's RMS against Depth with a per-Depth gain computed at control rate, not per sample.
  - No libm per sample: compute coefficients on a Depth change, with `fastExp2` for the log law.
- [ ] **Step 4: Run them and see them pass.** Run `make test`. Expected: `hadal test_layers: all checks passed`.
- [ ] **Step 5: Show each test can fail.** Remove the level normalisation, swap the rumble sides to independent noise, drop the 15 Hz high-pass, and add a fixed-period repeat to the generator, one at a time. See a test fail each time, then restore.
- [ ] **Step 6: Commit:** "Hadal: random source, Rumble and Hiss layers".

### Task 3: Crackle

**Files:**
- Create: `src/hadal/Crackle.hpp`.
- Modify: `test_layers.cpp`.

**Interfaces:** `struct Crackle`:
- `void setRate(float fs)`;
- `void seed(uint32_t s)`;
- `void setDepth(float d01)`;
- `void setDensity(float perSecond)` (default 10; Drift moves it);
- `void process(float& l, float& r)` gives the ticks, each panned at random, with a long-term RMS of 1.0 at density 10/s before gain.

- [ ] **Step 1: Write the failing tests:**
  - `crackle_rate`: over 60 s at density 10, the tick count is 600 ± 15 %. The inter-tick times are not periodic: their coefficient of variation is at least 0.7.
  - `crackle_level_flat_across_depth`: the long-term RMS at five Depths is within ±1.5 dB.
  - `crackle_peaks_bounded`: no sample exceeds the bound that maps to ±5 V at full.
  - `crackle_darker_and_longer_with_depth`: the mean tick centroid falls, and the mean tick length (to −40 dB) rises, from Depth 0 to 1.
  - `crackle_sizes_skewed`: the median tick peak is under 40 % of the 95th percentile.
  - `crackle_spread`: the tick pans span both sides, with at least 25 % of ticks in each outer third.
  - `crackle_no_rhythm`: no autocorrelation peak above 0.1 in the tick train from 50 ms to 10 s.
- [ ] **Step 2: Run them and see them fail.**
- [ ] **Step 3: Implement** the generator.
  - **Tick times:** a Poisson process, clustered by a slow random modulation of its rate.
  - **Tick sizes:** from a bounded skewed law, for example u³ scaled.
  - **Tick shape:** an exponentially decaying burst, with brightness and length set by Depth and its amplitude scaled so each tick's energy is constant.
- [ ] **Step 4: Run them and see them pass.**
- [ ] **Step 5: Show each test can fail.** Use a fixed tick interval, constant sizes, a fixed pan, and no energy normalisation, one at a time. See a test fail each time, then restore.
- [ ] **Step 6: Commit:** "Hadal: Crackle".

### Task 5: The engine

**Files:**
- Create: `src/hadal/HadalEngine.hpp` and `src/hadal/test_engine.cpp`.
- Modify: `tests.mk`.

**Interfaces (namespace `rka`):**
- `struct HadalPort { const float* v; int channels; }`, as Fog's.
- `struct HadalFrame`:
  - `enum { DEPTH, RUMBLE, HISS, CRACKLE, DRIFT, DEPTH_ATT, RUMBLE_ATT, HISS_ATT, CRACKLE_ATT, DRIFT_ATT, PARAMS_LEN };`
  - `float params[PARAMS_LEN];`
  - `HadalPort cv[5];`
  - `bool patched[5];`, outputs in id order: RUMBLE, HISS, CRACKLE, L, R.
- `struct HadalResult { float rumble, hiss, crackle, l, r; };`
- `class HadalEngine`:
  - `explicit HadalEngine(uint32_t seed)`;
  - `void setSampleRate(float fs)` ignores unusable rates;
  - `void reset()`;
  - `void process(const HadalFrame&, HadalResult&)`.

- [ ] **Step 1: Write the failing tests** in `test_engine.cpp`:
  - **Levels and the knob law:**
    - `full_levels`: at full, the Rumble and Hiss outputs are 1.6 V RMS ± 1 dB. The Crackle output's long-term RMS is the stated value ± 1 dB.
    - `audio_taper`: knob 0.5 gives −12 dB ± 0.5 against full; knob 0 gives silence (RMS < 1e-6).
    - `mix_ratio`: each layer's contribution to L/R equals its output times the fixed mix gain, within 1e-4 relative. Test this with one layer at a time.
    - `cv_law`: knob 0.5, attenuverter 1, CV +5 V gives the same as knob 1; attenuverter −1 with +5 V gives the same as knob 0; attenuverter 0 ignores the CV. Check every control.
    - `poly_cv_uses_channel_1`.
  - **Patching and normalling:**
    - `patched_layer_leaves_mix`: patching RUMBLE removes exactly rumble from L/R, and unpatching restores it.
    - `patch_unpatch_no_click`: the largest output step at the switch is at most 2× the steady largest step + 0.05 V.
    - `mono_normal`: with R unpatched, L equals the mono sum at about one side's loudness (±1 dB on noise); with R patched, L is the left mix.
    - `mono_normal_switch_no_click`.
    - `nothing_patched_no_work`: no generator advances while nothing is patched; check through a test-visible counter or flag.
  - **Smoothing and Drift:**
    - `square_cv_no_zipper`: 50 Hz square CV at full attenuverter on each input. The output stays finite, and the level envelope steps are bounded.
    - `drift_zero_static`: at Drift 0, the 1 s RMS and the centroid vary by under 0.5 dB and 3 % over 60 s.
    - `drift_full_moves_within_ranges`: at Drift full over 300 s, the level wanders within ±4 dB ± 1 and the centroid within about ±⅓ octave ± 0.1. The crackle rate stays within 3–25/s.
  - **Headroom and safety:**
    - `headroom`: all levels and Drift at full, every Depth: |output| ≤ 10 V; at defaults the soft limit never acts (a test-visible counter stays 0).
    - `stereo_mix`: the mix's mono-sum loss is ≤ 3 dB, and rumble's share is correlated at ≥ 0.8.
    - `seeds_differ_and_repeat`.
    - `bad_rate_ignored`: 0, −1, NaN, inf and 1e9 are ignored.
    - `nan_cv_safe`: NaN or inf on any CV keeps the outputs finite.
- [ ] **Step 2: Run them and see them fail.**
- [ ] **Step 3: Implement the engine.**
  - **Per sample:** read controls with the CV law, smooth gains and Depth, compute only the needed layers, form the outputs, the mix (with 10 ms per-layer mix fades on patch changes), the mono normal for L, and the soft limit.
  - **Per 32 samples:** advance Drift.
- [ ] **Step 4: Run them and see them pass.**
- [ ] **Step 5: Show each test can fail.** Use a linear taper, a mix gain of 1, no fade on a patch change, no mono normal, and no smoothing, one at a time. See a test fail each time, then restore.
- [ ] **Step 6: Commit:** "Hadal: engine".
