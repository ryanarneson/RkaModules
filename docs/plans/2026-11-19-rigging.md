# Rigging Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rigging, a 14 HP module of six tuned strings in the Instrument look: audio in keeps them ringing (a tuned drone), a trigger at STRUM strikes them (hits and stabs), with seven chords, a level per string, Ring, Damp, Spread and Mix.

**Architecture:**
- **Engine:** a Rack-free `rka::RiggingEngine` (`src/rigging/RiggingEngine.hpp`) built from small headers: the chord table, one string, the strike.
- **Module:** `Rigging.cpp` only maps ports, params and the menu onto the engine.
- **Panel:** the draft `"Rigging"` entry already in `tools/gen_panels.py` (uncommitted, marked MOCKUP), approved by the user in conversation with nothing changed.

**Tech Stack:** C++11 plugin code (Rack SDK 2.6.6), C++17 offline tests with `src/testing.hpp`, the Python 3 panel generator, Inkscape.

**Spec:** `docs/specs/2026-11-19-rigging-design.md`, mockup `docs/specs/2026-11-19-rigging-mockup.png`. Testing rules: `TESTING.md`. Reference to read, not copy: `~/ws/plugins/eurorack/rings/dsp/string.cc`, `string.h`, `plucker.h`, and `~/ws/plugins/eurorack/stmlib/dsp/delay_line.h`, `filter.h`. Read the spec before any task. Where this plan and the spec disagree, the spec wins; ledger the difference.

## Global Constraints

- **Build:** `RACK_DIR=$HOME/ws/sdk/Rack-SDK-2.6.6-mac-arm64`. Agents start Rack only through `make smoke`. Before every `make install`, `mac_dist` or `cross_build`: `tools/bump_version.sh "<what changed>"`, and clear older `rka-*` packages from Rack's plugins folder (#45).
- **Repo:** unit tests only; no audio, no test results beyond unit tests (they go on `/Volumes/share1/VCVRACK/`).
- **Every test is shown to fail** (a mutation, named in the ledger). No libm per sample (`src/FastMath.hpp`); NaN-safe; no allocation in `process`.
- **Ids** (panel, layout header, module, in this order): params `LEVEL_1`..`LEVEL_6`, `TUNE`, `CHORD`, `RING`, `DAMP`, `SPREAD`, `MIX`; inputs `VOCT`, `CHORD_CV`, `RING_CV`, `DAMP_CV`, `STRUM`, `L`, `R`; outputs `L`, `R`; light `STRIKE`. Slug `Rigging`.
- **Pitch:** string 1 = C2 (65.406 Hz) × 2^(Tune/12 + V/OCT), Tune −24..+24 semitones snapped (free with the menu's Free pitch); string n = string 1 × the chord's ratio. Each string clamped to 8 Hz .. min(12 kHz, 0.4 fs). Pitch changes glide (about 30 ms, in `RiggingTuning.hpp`).
- **Chords** (semitones above string 1 unless ratios; cents are detune): Unison 0×6 with −8, −4, 0, +3, +7, +11 cents; Octaves 0, 12, 12, 24, 24, 36 with the doubled pair members −5/+5 cents (strings 2/3 and 4/5); Fifths 0, 7, 12, 19, 24, 31; Minor 0, 7, 12, 15, 19, 24; Sus 0, 5, 7, 12, 17, 19; Cluster 0, 1, 2, 3, 4, 5; Bell ratios 1, 2, 2.4, 3, 4, 6. Default Fifths (index 2). Chord CV: 10 V across the seven (index = round(knob index + CV × 0.7) with hysteresis), clamped.
- **Ring:** T60 = 0.1 s × 600^knob (0.1 s .. 60 s), default 4 s; plus Ring CV / 10 V on the knob, clamped. Stated time is at Damp 0.
- **Damp:** 0..1, default 0.33, plus CV / 10 V. More Damp never rings longer.
- **Strike:** rising edge at STRUM (0.1 V / 1 V). String k (0..5) is struck k × Spread / 5 after the trigger; Spread = 1.5 s × knob³, default 60 ms. A new trigger drops the old rake's remaining strikes. One string alone peaks about ±2.5 V; six at once about ±6 V. The strike is not scaled by Ring's input share. Light: 0.1 s per trigger.
- **Input:** IN R normalled to IN L and IN L to IN R. Strings 1, 3, 5 (index 0, 2, 4) take L; 2, 4, 6 take R. The input's share into a string falls as Ring rises (constant loudness within 6 dB across Ring at defaults).
- **Levels:** 0..1, default 1, scale each string's output only, smoothed.
- **Output:** fixed pan positions (string 1 centred; in `RiggingTuning.hpp`), equal-power Mix (0 dry, 1 strings; default 1), soft limit on the strings (linear to its knee, never over ±10 V), no DC.
- **Bypass:** IN L to L, IN R to R, same normalling.
- **Rows** on the panel at 83, 102 and 116 mm.

## Review Focus

1. **Chord CV resting on a boundary, or moving fast:** the setting must not chatter, and each change must glide, not click.
2. **A sample-rate change while strings ring, and extreme rates (1 Hz to 768 kHz):** no crash, no stale delay length, 8 Hz still fits in memory at 768 kHz.
3. **A loud tuned input at a string's own pitch with Ring at 60 s** (resonance gain ×34 to ×186): bounded, no harsh edge, the ring time afterwards still right, silence returns.
4. **STRUM retriggered faster than the rake, up to audio rate:** bounded level and cost; the old rake dropped each time.
5. **Every level at 0, or Mix dry, for a long time:** exact silence from the strings, no denormal slowdown; V/OCT at ±10 V clamps and recovers.

Each has a test in the task named beside it below.

### Task 3: One string

**Files:** Create `src/rigging/String.hpp`, `src/rigging/test_string.cpp`. Modify `tests.mk`.

**Interfaces — Consumes:** `src/DelayLine.hpp`, `src/FastMath.hpp`, `RiggingTuning.hpp`. **Produces:**

```cpp
class String {
public:
	void setSampleRate(float fs);        // allocates for 8 Hz at fs (not in process); clears
	void setFrequency(float hz);         // the target; the string glides to it
	void setRing(float t60Seconds);      // at Damp 0
	void setDamp(float damp01);
	void snap();                         // jump to the targets (after a rate change, at start)
	float process(float in);             // one sample; `in` is added into the loop
	void clear();
	float frequency() const;             // the current (gliding) frequency
	float periodSamples() const;         // fs / frequency()
	float inputShare() const;            // the gain to give a steady input so loudness holds across Ring
};
```

Method (the builder may change it within the tests): Hermite read of `DelayLine` at the loop length minus the loop filter's delay; a per-trip gain g = 10^(−3 / (f × T60)); a damping low-pass whose cutoff follows the string's pitch and stays at least two octaves above it (as Rings); a bound on the loop that is exactly linear below its knee; DC blocked outside the loop. `inputShare` near √(1 − g²).

- [ ] **Step 1: Failing tests** (helpers: strike a string by feeding one period of seeded noise; measure the fundamental by a DFT peak with parabolic interpolation over at least 200 periods, an independent path; measure T60 from the fundamental's envelope by a windowed DFT at two times):
  - `tuning`: 30, 65.4, 220, 880, 2000 Hz × Damp 0, 0.5, 1 × 44.1, 48, 96 kHz: within 3 cents. 16 and 20 Hz: within 10 cents.
  - `ring`: Damp 0, strings 30 Hz to 1 kHz, Ring 20 periods .. 60 s (60 s measured over a 10 s window, extrapolated): T60 within 20 %. At 2 kHz, Ring 60 s: at least 10 s. At Damp 0.33: at least half of Ring for the same strings.
  - `damp`: more Damp, lower spectral centroid 0.5 s after a strike (Damp 0, 0.33, 0.66, 1, monotonic), and T60 never longer.
  - `glide`: a ringing string given a new frequency reaches it within 3 cents after 100 ms, and during the glide no sample-to-sample step exceeds twice the largest step of the 50 ms before it.
  - `input_share`: steady seeded white noise × `inputShare()` into a 65.4 Hz string at Damp 0.33: output RMS at Ring 0.3, 1, 4, 15 and 60 s within 6 dB of each other.
  - `bounded` (Review Focus 3): a ±10 V square at the string's pitch, Ring 60 s, 30 s long: |out| stays under the bound in `RiggingTuning.hpp`; then silence in: the ring's T60 (measured once the level is under the knee) still within 20 %, and the output is exactly 0 (or under 1e-20) within 20 Ring times at Ring 1 s.
  - `no_dc`: DC 5 V in for 10 s: the output's mean over the last second under 1 mV.
  - `rate_change` (Review Focus 2): `setSampleRate` 48 k → 96 k → 44.1 k while ringing: no crash (sanitizers in Task 6), tuning right afterwards; 768 kHz at 8 Hz allocates and rings.
- [ ] **Step 2:** Run. Expected: does not compile.
- [ ] **Step 3:** Implement.
- [ ] **Step 4:** Run: PASS. Mutations, each seen to fail: no filter-delay compensation (tuning); g from fs instead of f (ring); Damp cutoff fixed in Hz (damp at one pitch or tuning); no glide; `inputShare` = 1; bound removed; DC blocker removed.
- [ ] **Step 5:** Commit "Rigging: one string".

### Task 5: The engine

**Files:** Create `src/rigging/RiggingEngine.hpp`, `src/rigging/test_engine.cpp`. Modify `tests.mk`.

**Interfaces — Consumes:** Tasks 2 to 4. **Produces:**

```cpp
struct RiggingFrame {
	enum { LEVEL_1, LEVEL_2, LEVEL_3, LEVEL_4, LEVEL_5, LEVEL_6, TUNE, CHORD, RING, DAMP, SPREAD, MIX, PARAMS_LEN };
	float params[PARAMS_LEN];     // levels 0..1 (1); TUNE semitones (0); CHORD 0..6 (2); RING, DAMP, SPREAD, MIX 0..1
	float voct = 0, chordCv = 0, ringCv = 0, dampCv = 0, strum = 0;
	float inL = 0, inR = 0;
	bool inLPatched = false, inRPatched = false;
	bool freePitch = false;
};
struct RiggingResult { float l = 0, r = 0; bool light = false; };
class RiggingEngine {
public:
	explicit RiggingEngine(uint32_t seed);
	void setSampleRate(float fs);
	void reset();                                   // strings cleared
	void process(const RiggingFrame&, RiggingResult&);
	static float ringSeconds(float knob01);         // for the tooltip
	// For tests: string k's current frequency and the chord setting.
	float stringHz(int k) const;  int chord() const;
};
```

- [ ] **Step 1: Failing tests:**
  - `chord_pitches`: each chord, strike at Spread 0, long Ring, low Damp: the six strongest fundamentals in the mix (DFT, mono sum) match C2 × ratios within 5 cents; with V/OCT +1 V, doubled; with Tune −12, halved; free pitch off snaps Tune 0.4 to 0.
  - `drone`: seeded white noise ±5 V in, defaults: output peaks between 2.5 and 10 V after 5 s, RMS steady (last two seconds within 2 dB); across Ring 0.3 .. 60 s the RMS within 6 dB.
  - `strike_levels`: one level up, the rest 0: a strike peaks 1.5 to 4 V; all six, Spread 0: 4 to 9 V; the first 50 ms of a strike at Ring 60 s within 3 dB of Ring 1 s.
  - `levels`: level k at 0 removes string k's fundamental from the mix (60 dB down) and leaves the others; raising it mid-ring brings it back without a step; all levels 0 and Mix dry: the strings' part exactly 0 (Review Focus 5).
  - `input_routing`: L only patched equals R only patched (same signal), sample for sample; both patched with different signals: strings 1, 3, 5 follow L (their fundamentals vanish when L is silent).
  - `stereo`: string 1 equal in L and R; strings 2 to 6 each louder on one side, alternating; L + R keeps all six within 1 dB of the sum of their side levels (no cancellation).
  - `mix`: Mix 0 gives the input unchanged (normalled); Mix 0.5 has both at −3 dB.
  - `cv`: Ring knob 0.5 with Ring CV +5 V rings as long as knob 1.0 with no CV (measured T60 within 20 %), and −5 V as knob 0; Damp knob 0.5 with CV ±5 V gives the same centroid as knob 1 and knob 0. `chord_cv_no_chatter` (Review Focus 1): Chord CV dithering on a boundary during a drone: `chord()` changes at most once; a Chord change mid-drone makes no step beyond twice the drone's largest in the 50 ms before.
  - `strum_edges`: 0.1 V / 1 V Schmitt; a held gate is one strike; NaN on STRUM is no strike; the light is on for 0.1 s per trigger.
  - `clamps` (Review Focus 5): V/OCT +10 V and −10 V: every `stringHz` inside 8 Hz .. min(12 kHz, 0.4 fs), output finite; back to 0 V: pitches right again within 0.2 s.
  - `nan_inputs`: NaN and ±inf on every input and CV: output finite; reads as 0 V.

- [ ] **Step 3:** Implement. Controls every 16 or 32 samples; per-sample: Schmitt, strike, six strings, pan, limit, mix. Reuse Ballast's limit curve (identity to its knee).
