# Splice: a precision adder

Status: idea, 2026-11-15. Not designed. One of six 2 HP utilities.

![mockup](splice-mockup.svg)

**What it is.** Sums four inputs to one output at unity gain, for mixing CVs or transposing a sequence.

**The name.** A splice, which joins ropes into one.

**Sketched controls.** Four inputs, a light for the sum, one output.

**Open questions.** Whether any input needs an invert switch; clipping behaviour; an offset when nothing is patched; polyphonic summing.
