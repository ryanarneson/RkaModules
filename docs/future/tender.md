# Tender: aux sends for Ballast

Status: idea, 2026-11-26. Not designed; no sketch yet. The name is a
working title and has not been checked against the VCV Library. Added
when the user asked what the roadmap was missing. Ballast's manual has
said since it was built that aux sends "may follow".

**What it is.** An expander for Ballast, as Pan is: two stereo send
buses, with a send level for each of Ballast's four channels, and two
stereo returns mixed back into Ballast's output. One Fog and one Wake
then serve every channel, each channel taking as much as it wants.

**The name.** A ship's tender is the small boat that carries things out
from the ship and back again: a send and a return.

**Why now.** Fog, Wake, Spindrift and Eddy are built and Doldrums is
next. Each is most useful as a shared effect, and today every channel
that wants reverb needs its own Fog or a mixer from another maker.

**Sketched controls.** Not drawn. Likely 8 to 10 HP. For each of the
four channels, a Send A and a Send B knob. For each bus: a stereo send
output on ivory tiles, a stereo return input and a Return level. A
Pre / Post switch per bus (before or after the channel's level).

**Open questions.** Whether sends are taken after Pan when a Pan
expander is also fitted, and so how two expanders share Ballast's right
side (Pan's design settles the chain; read it first); CV over send
levels, which is what makes a sound drift into the reverb by itself and
may matter more here than the knobs; one bus in a narrower panel or two;
whether the returns join before or after Ballast's soft limit and DC
blocker (before, so the output stays safe); a mono return normalled to
both sides.
