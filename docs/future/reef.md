# Reef: two attenuators

Status: **dropped** by the user, 2026-11-27: Tackle (four attenuverters
with offset) covers it. Kept for the record. Before that: an idea,
2026-11-15, not designed, one of six 2 HP utilities.

![mockup](reef-mockup.svg)

**What it is.** Two independent attenuators.

**The name.** Reefing a sail: taking some of it in.

**Sketched controls.** Two channels, each a knob, an input and an output.

**Open questions.** Attenuators or attenuverters (Tackle already inverts); whether an unpatched input supplies a fixed voltage so each channel doubles as a manual offset; whether B's input takes A's when unpatched.
