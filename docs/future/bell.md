# Bell: a manual trigger

Status: idea, 2026-11-15. Not designed. One of six 2 HP utilities.

![mockup](bell-mockup.svg)

**What it is.** A button that sends a trigger and a gate, and converts an incoming gate to a trigger.

**The name.** A ship's bell.

**Sketched controls.** A lit Strike button, a Gate input, Trig and Gate outputs.

**Open questions.** Trigger length; whether the button latches with shift-click as Sway's Hold button does; whether the gate input and the button combine.
