# Hold: sample and hold

Status: idea, 2026-11-15. Not designed. One of six 2 HP utilities.

![mockup](hold-mockup.svg)

**What it is.** Samples its input on each trigger and holds the value.

**The name.** A ship's hold, where cargo is kept.

**Sketched controls.** Input, Trig input with a light, a Track button for track-and-hold, output.

**Open questions.** Internal noise when the input is unpatched; whether Track is a button or a second mode on the trigger; polyphony.
