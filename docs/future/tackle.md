# Tackle: four attenuverters with offset

Status: idea, 2026-11-15. Not designed.

![mockup](tackle-mockup.svg)

**What it is.** The utility every patch needs: four channels that scale
and shift a voltage.

**The instrument.** Block and tackle. Each pulley sets a ratio, and one
rope runs through them all. The brass rope on the panel runs down through
the four inputs from an anchor point at the top: an unpatched input takes
its signal from the one above.

**Sketched controls.** Per channel: an input, a Scale dial on a small
enamel face marked −1 to +1, a Shift knob, an output. A trace runs
straight across each row from input to output.

**Open questions.** What feeds the first input when nothing is patched (a
fixed voltage would make each channel a manual offset); Shift range;
whether outputs also mix downward; lights for polarity.
