SHOAL

Listening list · build 2.0.39 · 2026-11-24

Shoal runs the Ornament & Crime firmware: thirteen apps, a friendly mode with a mouse list of each app's settings, a hardware mode with the firmware's own menu, and a scope on the upper screen. This list covers the panel, both modes, the apps the friendly list covers best, the scope, and saving. Ticks and notes are kept in this browser; Copy notes puts them on the clipboard to paste back. Items marked untested are paths no automated run could reach: everything you see on the screens, the lights, the tooltips and menus, and how the panel looks.

WhatThe question
SMOOTH VIEWSIn friendly mode Quadraturia, Piqued, Dialectic Ping Pong, Low-rents, Automatonnetz and Harrington 1200 draw their own smooth views. Deliberate differences from the hardware: Piqued's envelope shapes are dropped, and Low-rents is mirrored. Do they read better than the o_C screen, or would you rather match the hardware?
FIXED SCALESEach trace lane has one fixed scale for its app (0 to +5 V for Piqued, 0 to +6.25 V for Dialectic Ping Pong, the full range for Quadraturia), and the window is a fixed 4 seconds. Is that right, or do you want a zoom or time base?
HARDWARE MODE SCREENHardware mode shows the o_C screen exactly: no dividers, letters or smooth views. Keep it as a faithful copy, or add the lane letters there too?
START AT 0 VThe outputs start at 0 V when added, initialized or loaded, where the hardware starts near its top voltage. Is 0 V the better choice for a rack?
HARDWARE-ONLY EDITORSUser scale notes, Sequins steps, Acid Curds chords, Automatonnetz cells and References' Autotune still need hardware mode. Which one do you reach for most, so it gets a mouse editor first?
MISSING OPTIONSThe right-click choices for the ±5 V input range, encoder acceleration and the app are not there yet. Which do you miss?
CPU (issue #51)The output history is copied in full on every published frame, even in hardware mode and in apps that do not draw it. The average cost is tiny. Do several Shoals in one patch still feel light?

Patches

1. A canon from one line

Squall Step → Shoal CV 1 · Squall Gate → Shoal TRIG 1 · Shoal A → Fathom 1 V/oct · Shoal D → a second Fathom 1 V/oct

CopierMaschine, the default. Pick a Scale in the list. Both voices play the same melody, D three clocks behind A. Raise buf.index to push them further apart.

2. Quantised weather

Squall Step → Shoal CV 1 · Squall Gate → Shoal TRIG 1 · Shoal A → Rigging 1 V/oct (STRUM unpatched)

Quantermain, Trigger source TR1, a Scale chosen. Each event gives one note of the scale and Rigging strikes on each new note.

3. Four drones in turn

Hadal Hiss, Rumble, Crackle → Ballast channels 1 to 3 left · Shoal A to D → Ballast channel 1 to 4 level CV

Quadraturia with Phase/frq sprd turned up: the channels fade one after another. The LFOs are not centred on 0 V, so set Offset and Output range until each closes fully.

4. Chaos on a filter

Fathom Left → Narrows Left · Shoal A → Narrows FM · Shoal B → Fog Size CV · Narrows Left → Fog Left

Low-rents. A and B come from one attractor, so the filter and the room move in a related way that never repeats. A slow Sway Sine into Shoal CV 2 moves Rho/c 1 from calm to wild. A gate into TRIG 4 freezes the lot.

5. Chords on a pedal bass

Sway End of cycle → Shoal TRIG 2 · a second Sway End of cycle → TRIG 3 · Shoal B → Fathom 1 V/oct · Shoal A → a second Fathom 1 V/oct

Harrington 1200. B follows the chord while A, the root, stays as a bass. Use the scope: the circle shows the notes and the moves list shows P, L and R.

6. Envelopes from one clock

Sway End of cycle → Shoal TRIG 1 · Shoal A → Sluice A level CV · Hadal Hiss → Sluice A

Piqued. Shape Attack and Decay, then thin the triggers with Eucl length and Fill. The scope shows A's envelope as a smooth trace.

7. A bass line with its own gate

Sway End of cycle → Shoal TRIG 1 · Shoal A → Fathom 1 V/oct · Shoal C → Beacon Gate · Beacon Envelope → Sluice A level CV

Sequins. A new module plays one note, so edit the steps in hardware mode first (click Steps, switch UI MODE, press R). C is the gate by default.
