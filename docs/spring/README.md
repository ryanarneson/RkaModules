# Spring

Neap's expander, 6 HP: sixteen outputs made from Neap's eight cycles
(folds, minimums and maximums, triggers and steps). Place it directly
against Neap's right side, or right-click Neap and choose **Add Spring
expander**.

The manual is in [docs/neap/README.md](../neap/README.md); Spring is the
section of that name. The QA notes are in [QA.md](QA.md).
